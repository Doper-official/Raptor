# RAPTOR GAME ENGINE
## Features
- Renderer: Custom Vulkan Engine
- C++ standard: 23
- windowing and game inputs: GLFW
- object loading: wavefront .obj / .objmodel
- CMake build system

## Tech Stack
- Languages used: C++ 23, Cmake
- graphics API: Vulkan
- Windowing: GLFW
- Math libs: GLM
- Model Loading: TinyOBJLoader
- Build System: CMake

## Aim
- make a custom modular engine
- turn the current system into a library and use Java based control system
- open source under liscence regulations
- experiment with efficient / weird graphics techniques
